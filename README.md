# Crowders Camps calendar: website copy

Upload this whole folder to a GitHub repository and turn on GitHub Pages for it. `index.html` is the calendar page and `assets/` holds the fonts and logo; neither changes day to day. `data.js` holds the events and is the only file the daily update replaces.
`embed.html` is the snippet to paste into the website, which keeps the frame the right height.

This copy is regenerated by `../build.py` from the CampWise data. Staff appear only as first name + last initial; phone numbers, emails and other personal information are never included.

Link settings (also work in the embed): `?camp=ridge` (or `smcc`, `springs`, comma-separated), `?view=list`, `?details=meal,act`, `?who=Eli` (one staff member's shifts; use + for spaces, like `who=Justin+B`).

Staff name bar: tap a name to see only that person's shifts. `data.js` includes Noah's staff assignments (added 2026-11-05), applied by the events-db build; names are first name or first + last initial only.
Detail keys: arr (arrival & departure), meal, prog (program), act (activities), space (meeting spaces), lodge, rent (rentals), pkg (package).

Live address: https://crowders-camps.github.io/crowders-calendar/ (moved from natecrowders.github.io on 2026-11-02).

Meals: when Event details shows Meals, each Breakfast, Lunch and Dinner gets a one-line "Menu:" summary read live from the Kitchen Prep Builder (its public relay feed, the same one the guest menu uses). Nothing from the prep tool is stored here; a meal with no menu posted for that date and camp simply shows no summary.

## Page changes from the Master Calendar (added 2026-11-05)

The page (`index.html`) is built from the Crowders Camps Master Calendar artifact by `tools/sync_page.py`,
only when someone asks Claude to push changes live. Private parts of the artifact (marked `@private`) are
left out, and the result is checked against `tools/forbidden.json` before it can be published. Team members
without GitHub access publish through the calendar publisher in `publisher/`. Steps: `tools/SYNC.md`.
`data.js` is still replaced only by the daily build.
